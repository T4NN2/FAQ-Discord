XMusic is a Discord music bot that plays audio in voice channels and can stay in a channel 24/7. It is controlled with slash commands and a button control panel.

Tiếng Việt: XMusic là bot nhạc Discord phát nhạc trong voice channel, có chế độ treo 24/7, điều khiển bằng slash command và bảng nút bấm.

Features

  • Play music from a link or by name (YouTube, Spotify, SoundCloud, TikTok)
  • Queue, loop (off / queue / single track), shuffle, volume, audio effects
  • Button control panel (/panel)
  • 24/7 mode (/247) and lofi radio (/lofi)
  • Automatic rejoin of the 24/7 channel after a disconnect

Commands

CommandDescription
/play <link or name>Play a track
/pause · /resumePause / resume
/skipSkip the current track
/stopStop and clear the queue
/queueShow the queue
/nowplayingShow the current track
/volume <0-100>Set the volume
/loopLoop: off / queue / single track
/shuffleShuffle the queue
/effectToggle an audio effect
/panelPost the control panel
/lofiPlay lofi radio 24/7
/247Toggle 24/7 mode in the voice channel
/leaveLeave the voice channel

Permissions requested

View Channels, Send Messages, Embed Links, Attach Files, Read Message History, Use Application Commands, Connect, Speak, Use Voice Activity. XMusic does not request Administrator, Manage Server, Manage Roles, Kick or Ban.

Privileged intents

XMusic does not use the Message Content, Server Members or Presence intents. It only reacts to slash commands and button interactions.
