# XMusic

XMusic is a Discord music bot that plays audio in voice channels and can stay in a channel 24/7.
It is controlled entirely with slash commands and a button control panel.

> Tiếng Việt: XMusic là bot nhạc Discord phát nhạc trong voice channel, có chế độ treo 24/7. Điều khiển bằng slash command và bảng nút bấm.

## Features
- Play music from a link or by name (YouTube, Spotify, SoundCloud, TikTok)
- Queue, loop (off / queue / single track), shuffle, volume, audio effects
- Button control panel (`/panel`)
- 24/7 mode (`/247`) and lofi radio (`/lofi`)
- Automatic rejoin of the 24/7 channel after a disconnect

## Commands
| Command | Description |
|---|---|
| `/play <link or name>` | Play a track |
| `/pause` / `/resume` | Pause / resume |
| `/skip` | Skip the current track |
| `/stop` | Stop and clear the queue |
| `/queue` | Show the queue |
| `/nowplaying` | Show the current track |
| `/volume <0-100>` | Set the volume |
| `/loop` | Loop: off / queue / single track |
| `/shuffle` | Shuffle the queue |
| `/effect` | Toggle an audio effect |
| `/panel` | Post the control panel |
| `/lofi` | Play lofi radio 24/7 |
| `/247` | Toggle 24/7 mode in the voice channel |
| `/leave` | Leave the voice channel |

## Permissions requested
View Channels, Send Messages, Embed Links, Attach Files, Read Message History,
Use Application Commands, Connect, Speak, Use Voice Activity.

XMusic does **not** request Administrator, Manage Server, Manage Roles, Kick or Ban.

## Privileged intents
XMusic does not use the Message Content, Server Members or Presence intents.
It only reacts to slash commands and button interactions.
